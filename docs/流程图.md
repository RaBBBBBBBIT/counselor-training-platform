# 流程图 —— 辅导员训练平台

> 本文件填补作业文档「三、流程图」的空白，使用 Mermaid 语法描述核心业务流程。渲染环境若需将代码块视为 Mermaid，请用标准 mermaid 代码围栏（见各图下方说明）。

## 1. 用户登录与权限分流

```mermaid
flowchart TD
  A[开始] --> B[输入用户名密码]
  B --> C{认证成功?}
  C -- 否 --> D[返回 401 未认证]
  C -- 是 --> E[签发 JWT，含角色与院系]
  E --> F{角色判定}
  F -- ADMIN --> G[题库/正式比赛/日常练习/成绩全量管理]
  F -- ORGANIZER --> H[现场比赛组织与展示]
  F -- COUNSELOR --> I[比赛练习 + 本人成绩查询]
  F -- DEPT_HEAD --> J[本院系辅导员成绩查询]
```

## 2. 题库管理与试卷生成

```mermaid
flowchart TD
  A[ADMIN 创建题库] --> B{是否共享?}
  B -- 是 --> C[共享题库：全体只读]
  B -- 否 --> D[自建题库：ADMIN 增删改查]
  D --> E[维护题目]
  E --> F{生成试卷方式}
  F -- 随机 --> G[按题型/数量/分值随机抽题并快照]
  F -- 固定 --> H[手动选题并固定顺序]
  G --> I[试卷]
  H --> I
  E --> J{删除题目}
  J --> K{被试卷使用 或 在共享题库?}
  K -- 是 --> L[拒绝删除]
  K -- 否 --> M[删除成功]
```

## 3. 正式比赛流程

```mermaid
flowchart TD
  A[创建比赛：默认 2 笔试环节 + 3 面试环节] --> B[配置环节与参赛人员]
  B --> C[状态：未开始]
  C --> D[开始：进行中]
  D --> E[笔试答题：客观题 + 主观题]
  E --> F[面试环节]
  F --> G[结束比赛]
  G --> H[评分：客观题自动 + 主观题人工]
  H --> I[阶段成绩] --> J[总成绩] --> K[排名]
```

## 4. 比赛练习答题流程

```mermaid
flowchart TD
  A[辅导员进入比赛练习] --> B{答题模式}
  B -- 练习模式 --> C[答一题并提交]
  C --> D[立即查看该题答案]
  D --> E{还有题目?}
  E -- 是 --> C
  E -- 否 --> F[完成]
  B -- 模拟模式 --> G[全部作答]
  G --> H{是否全部答完?}
  H -- 否 --> I[不允许提交/不允许看答案]
  H -- 是 --> J[一次性提交后查看答案]
  B -- 正式比赛 --> K[笔试答题]
  K --> L[客观题自动判分 / 主观题待评分]
```

## 5. 成绩查询与评分流程

```mermaid
flowchart TD
  A[客观题] --> B[系统自动判分：objective_score]
  C[主观题] --> D[待评分 PENDING]
  D --> E[ADMIN 人工评分或文件导入]
  E --> F[写入 subjective_score]
  B --> G[基础知识成绩 = 客观分 + 主观分]
  F --> G
  G --> H[阶段成绩：按环节求和]
  H --> I[总成绩：各环节求和]
  I --> J[排名：总成绩降序，同分姓名拼音升序]
  J --> K{查询者角色}
  K -- ADMIN --> L[返回全量成绩]
  K -- COUNSELOR --> M[返回本人成绩]
  K -- DEPT_HEAD --> N[返回本院系辅导员成绩]
```

## 6. 现场比赛流程

```mermaid
flowchart TD
  A[现场组织者] --> B{现场比赛类型}
  B -- 学情辨析 --> C[按编号抽取学生照片与姓名]
  C --> D[参赛者现场辨析作答]
  D --> E[组织者查看参考答案]
  B -- 案例分析 --> F[按编号分组]
  F --> G[抽题]
  G --> H[展示题目]
  B -- 谈心谈话 --> I[按编号抽题]
  I --> J[展示题目]
```
