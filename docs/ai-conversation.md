# ai-conversation.md —— 与 AI 对话记录（SDD 需求共创）

> 本文档记录「辅导员训练平台」需求澄清阶段人与 AI 的协作对话，是 specs/spec.md 的生成过程证据，也是作业验收内容「与 AI 对话的内容」的交付物。所有问答结论均已固化进 spec.md，二者一致、无矛盾。

## 1. 对话背景

- **角色设定**：AI 扮演经验丰富的产品经理，负责通过提问澄清需求、挖掘边缘场景。
- **目标**：将「搭建辅导员训练平台」这一模糊想法，共创为一份清晰、结构化、无歧义的 spec.md（只关注需求，不涉及技术）。
- **初始想法**：面向高校辅导员队伍，搭建覆盖日常学习、模拟演练、正式比赛的训练平台，实现以赛促学、以练促能。

## 2. 需求澄清问答（多轮头脑风暴）

### Q1：系统有哪些使用者？各自做什么、看什么？

**A**：四类角色，职责与约束如下——业务管理人员（题库/比赛/练习/成绩管理）、现场组织者（现场比赛）、辅导员（比赛练习、查本人成绩）、院系学工负责人（查本院系辅导员成绩）。

**固化**：spec.md 第 3 节角色定义与 3.1 权限矩阵。

### Q2：题库如何区分「自有」与「共享」？共享题库谁可编辑？

**A**：题库分「自建」与「共享」。共享题库（含其中题目）对**所有登录用户只读**，任何角色（含 ADMIN）都不可增删改。题目不单独设共享标记，随所属题库决定。

**固化**：FR-QB-1/2/6、BR-QB-2、术语表。

### Q3：题目删除有没有限制？

**A**：有。只有**同时满足**「未被任何试卷使用」且「不在共享题库」才可删除，任一不满足即拒绝。

**固化**：FR-QB-5、BR-QB-1、E-1/E-2。

### Q4：试卷怎么生成？

**A**：两种方式——随机（按题型/数量/分值抽题，生成时快照固化）与固定（手动选题、固定顺序）。抽题数超过可用数时报错。

**固化**：FR-QB-4、E-3。

### Q5：正式比赛的「环节」如何设置？

**A**：默认笔试 2 环节 + 面试 3 环节，可在默认基础上增删改顺序。笔试环节含客观+主观；面试环节仅含主观题（评委评分）。比赛状态按 未开始→进行中→已结束 单向流转。

**固化**：FR-COMP-1/2/3、BR-COMP-1、术语表。

### Q6：练习与模拟的答题规则有何区别？

**A**：练习模式——答一题、立即看该题答案；模拟模式（含学情辨析批次）——全部答完一次性提交后才能看答案。练习/模拟成绩独立记录，不参与正式比赛排名。

**固化**：FR-PRAC-2/3、FR-EXAM-1/2、BR-EXAM-1/2、BR-SCORE-7。

### Q7：成绩如何计算？客观题怎么判分？

**A**：基础知识成绩 = 客观分 + 主观分。客观题系统自动判分：单选/判断一致得满分否则 0；**多选必须完全一致才得满分，不设部分分**。主观题人工评分，范围 [0, 该题分值]，未评分记「待评分」不计入。

**固化**：FR-SCORE-1/2/3、BR-SCORE-1/2/3、E-10、E-12。

### Q8：阶段成绩、总成绩、排名如何定义？

**A**：阶段成绩 = 该环节题目得分之和；总成绩 = 各环节阶段成绩之和；排名按总成绩降序，**同分按姓名拼音升序，并列名次连续编号（1、2、2、4）**。存在待评分主观题时该选手标「待评分」，暂不计入最终排名。

**固化**：FR-SCORE-4/5/6、BR-SCORE-4/5/6、E-11。

### Q9：成绩查询的权限范围如何精确界定？

**A**：ADMIN 查全量；COUNSELOR 仅本人；DEPT_HEAD 仅本院系辅导员（department_id 等于本人且 role=COUNSELOR）；ORGANIZER 无查询权限。

**固化**：spec.md 3.1、FR-SCORE-7、E-5/E-6。

### Q10：主观成绩如何导入导出？

**A**：ADMIN 用 CSV/XLSX 批量导入主观分，覆盖式更新；越界（<0 或 > 该题分值）的行拒绝并逐行反馈。导出字段含比赛/批次、环节、参赛人员、题目、主观分、评分状态。

**固化**：FR-SCORE-8/9、E-7。

### Q11：现场比赛具体做什么？

**A**：现场组织者主持三类——学情辨析（按编号抽学生照片/姓名，组织者看参考答案）、案例分析（按编号分组、抽题、展示题目）、谈心谈话（按编号抽题、展示题目）。学生素材由 ADMIN 维护，ORGANIZER 仅使用。

**固化**：FR-LIVE-1/2/3/4。

### Q12：哪些内容明确不在本期范围内？

**A**：移动端 App、SSO 单点登录、消息推送/短信/邮件通知、面试环节实时音视频。

**固化**：spec.md 1.3 范围边界。

## 3. 关键决策记录（消除歧义的拍板项）

| 决策点 | 拍板结论 | 理由 |
| --- | --- | --- |
| 多选题判分 | 完全一致才得分，不设部分分 | 避免部分分的复杂规则，保证无歧义 |
| 面试环节 | 仅主观题，评委评分 | 面试无标准客观答案 |
| 排名并列 | 同分按姓名拼音升序、连续编号 | 保证稳定可复现的排名 |
| 待评分主观题 | 不计入、标 PENDING、暂不排名 | 保证成绩完整前不产生错误排名 |
| 共享题库权限 | 全员只读，含 ADMIN | 明确「只能查看」的边界 |
| 删除前置条件 | 未被引用 且 非共享，两者同时满足 | 精确对应作业约束 |
